All results are on held-out test maps; learned methods are the mean over 3 training seeds.

## Setup

### Task

Flatland 4.3: all trains share one rail network and must reach their targets before the time limit. Unit speed, no malfunctions, no intermediate stations (origin to target only); trains may stop and wait anywhere. 5 actions, invalid ones masked. All learned methods see the same depth-3 tree observation (1020 features per train). One PPO epoch = 1024 env steps.

### Baselines (no learning)

| Method | Kind | What it does | Tuning |
|---|---|---|---|
| Prioritized planning (centralized reference) | Centralized planner | Plans trains one at a time with A* in space-time, reserving cells so later trains avoid earlier ones. Sees the whole map and all trains (upper reference). | None |
| Shortest path + departure cap | Heuristic | Shortest path, but at most k trains on the map at once; others wait at their start. | k tuned per size on validation |
| Shortest path | Heuristic | Every train follows its own shortest path, no coordination. | None |
| Random | Heuristic | Uniform random valid action. | None |

### Evaluation protocol

- **Maps**: NeurIPS 2020 Flatland competition generator; size, cities and time limit grow with the train count.
- **Validation** (map seeds 2000–2019): only used to pick each run's checkpoint (highest competition score at the sizes it trained on) and to tune departure caps.
- **Test** (map seeds 1000–1019): different maps, never seen in training or selection. RL trained only at 5 trains is tested zero-shot at larger sizes.
- **Per test map**: 3 sampled-policy episodes (reported here) + 1 deterministic episode. Deterministic baselines play each map once; random plays it 3 times.

### Metrics

- **Completion**: share of trains that reach their target.
- **Competition score**: 1 − mean(arrival time, or the time limit if not arrived) / time limit. The official ranking metric; it rewards arriving fast.
- **Deadlock rate**: share of trains ever deadlocked. **Delay Gini**: how unequal delays are across trains (0 = equal).
