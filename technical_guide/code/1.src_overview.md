# src 包结构

[中文](#chinese) | [English](#english)

`src` 是项目的 Python 包。在仓库根目录运行脚本或 notebook 时，可以通过 `src` 导入各模块。

| 目录 | Python 包名 | 用途 |
|---|---|---|
| `src/agent` | `src.agent` | Actor、Critic 及其独立、共享和中央实现 |
| `src/model` | `src.model` | 核心策略网络和价值网络 |
| `src/reward` | `src.reward` | 训练奖励组件 |

每个目录通过 `__init__.py` 声明为 Python 包。`src.agent` 同时提供 Actor 和 Critic 类的统一导入入口：

```python
from src.agent import IndependentActor, ShareNetworkActor, CentralizedActor
from src.agent import IndependentCritic, ShareNetworkCritic, CentralizedCritic
```

也可以直接从具体模块导入：

```python
from src.agent.actor import Actor
from src.agent.critic import Critic
```

模型接口规范见 [Actor](2.actor.md) 和 [Critic](3.critic.md)。

# src Package Structure

`src` is the project's Python package. When running scripts or notebooks from the repository root, import project modules through `src`.

| Directory | Python package | Purpose |
|---|---|---|
| `src/agent` | `src.agent` | Actor and Critic classes, including independent, shared, and centralized implementations |
| `src/model` | `src.model` | Core policy and value networks |
| `src/reward` | `src.reward` | Training reward components |

Each directory contains an `__init__.py` file that declares it as a Python package. `src.agent` provides a common import entry point for Actor and Critic classes:

```python
from src.agent import IndependentActor, ShareNetworkActor, CentralizedActor
from src.agent import IndependentCritic, ShareNetworkCritic, CentralizedCritic
```

You can also import directly from a specific module:

```python
from src.agent.actor import Actor
from src.agent.critic import Critic
```

See [Actor](2.actor.md) and [Critic](3.critic.md) for the model interface specifications.
