# 实验环境配置

[中文](#chinese) | [English](#english)

本文按类别列出环境配置的原始变量。具体数值后续确定。

## 1. 地图生成

- **地图宽度**：地图横向的格子数量。
- **地图高度**：地图纵向的格子数量。
- **城市数量上限**：官方地图生成器允许生成的最大城市数量。
- **城市分布方式**：选择网格分布或随机分布。
- **城市之间的轨道数量上限**：限制城市之间生成的轨道数量。
- **城市内部的轨道对数量上限**：限制城市内部生成的轨道对数量。

## 2. 列车生成

- **列车数量**：环境中生成的列车总数。
- **最大速度及其分配概率**：设置可用的最大速度，以及每列车被分配到各档最大速度的概率。例如，速度 1 和速度 0.5 的概率各为 50%.

## 3. 官方观测

- **观测类型**：使用以下官方预设，各类型对应的参数见表格。

| 观测类型 | 内容 | 该类型的配置参数 |
|---|---|---|
| 官方树形观测 | 从列车所在位置沿轨道分支展开，提供各分支上的距离和列车信息。 | 最大深度；是否启用官方路径预测器；启用时的预测步数。 |
| 官方展平并归一化的树形观测 | 将树形观测整理成一维数组，并对数值进行归一化处理。 | 最大深度；归一化距离参数；是否启用官方路径预测器；启用时的预测步数。 |
| 官方全局观测 | 提供整张地图的轨道、列车和目标位置信息。 | 无树形深度或路径预测参数。 |

## 4. 途经站要求

- **是否要求中途停靠**：选择是否要求列车服务途经站。
- **任务线路长度**：通过官方任务生成器设置任务包含的地点数量，其中包括起点和终点。增加线路长度可以生成包含途经站的任务，实际生成结果受地图条件约束。

## 5. 时刻要求

- **是否考核时刻要求**：选择是否考核最早出发、途经站离开时间和最晚到达。

各列车的具体时间表使用官方生成结果。

## 6. 全局时限

- **整局最大步数**：使用官方生成的默认时限，或指定整局步数上限。

# Experiment Environment Configuration

This document lists the original environment configuration variables by category. Specific values will be determined later.

## 1. Map Generation

- **Map width**: Number of cells across the map.
- **Map height**: Number of cells down the map.
- **Maximum number of cities**: Maximum number of cities allowed by the official map generator.
- **City placement**: Grid placement or random placement.
- **Maximum number of tracks between cities**: Limit on generated connections between cities.
- **Maximum number of track pairs within a city**: Limit on generated track pairs inside each city.

## 2. Train Generation

- **Number of trains**: Total number of trains generated in the environment.
- **Maximum speeds and their assignment probabilities**: Available maximum speeds and the probability of assigning each speed to a train. For example, maximum speeds of 1 and 0.5 can each have a 50% probability.

## 3. Official Observations

- **Observation type**: Use the following official presets. Their configuration parameters are listed in the table.

| Observation type | Content | Configuration parameters |
|---|---|---|
| Official tree observation | Expands along track branches from the train's position, providing distances and train information along each branch. | Maximum depth; whether to enable the official path predictor; prediction horizon when enabled. |
| Official flattened and normalized tree observation | Converts the tree observation into a one-dimensional array and normalizes its values. | Maximum depth; normalization distance parameter; whether to enable the official path predictor; prediction horizon when enabled. |
| Official global observation | Provides track, train, and target locations across the entire map. | No tree-depth or path-prediction parameters. |

## 4. Intermediate Stops

- **Whether intermediate stops are required**: Whether trains must serve intermediate stations.
- **Task line length**: Number of locations in a task, configured through the official task generator, including the origin and destination. Increasing the line length allows tasks with intermediate stations; the generated result depends on map conditions.

## 5. Timetable Requirements

- **Whether timetable requirements are assessed**: Whether to assess earliest departure, departure times at intermediate stations, and latest arrival.

Use the officially generated timetable for each train.

## 6. Global Time Limit

- **Maximum steps per episode**: Use the default limit generated by the official environment or specify an episode step limit.
